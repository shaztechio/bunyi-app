# CLAUDE.md

This repo uses **`AGENTS.md`** as the canonical guidance for agents and
developers. Start there:

- [`/AGENTS.md`](AGENTS.md) — multi-platform overview + the parity rule
- [`/spec/FEATURES.md`](spec/FEATURES.md) — feature spec (source of truth)
- [`/spec/DATA-FORMATS.md`](spec/DATA-FORMATS.md) — on-disk formats
- [`/apps/macos/AGENTS.md`](apps/macos/AGENTS.md) — the macOS app (Swift/MLX)
- [`/apps/dotnet/AGENTS.md`](apps/dotnet/AGENTS.md) — the Windows+Linux app (.NET/Avalonia)

Every `AGENTS.md` has a `CLAUDE.md` beside it, in the same directory, whose job
is to point at it. The guidance lives in one file per directory rather than two;
this one exists so that either name leads to it.
