// What CsWin32 generates interop for: the modern UI Automation *client*. It is
// the only client that can read UIA_LiveSettingPropertyId (30135) or receive
// UIA_LiveRegionChangedEventId (20024). .NET's managed System.Windows.Automation
// client rejects the first outright — it hands back an ArgumentException object
// reading "Unsupported Property", measured — and accepts a subscription to the
// second while delivering nothing. Those two are #192's question, so this
// second client is not a nicety.
//
// Generated from the official Win32 metadata rather than written by hand:
// IUIAutomationElement's vtable is eighty-odd slots deep and a wrong guess
// there is a silent misread, not a compile error.
