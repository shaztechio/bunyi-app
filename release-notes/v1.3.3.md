# Bunyi 1.3.3 — Mac

## More room to write

Script, style instruction and voice description editors can now be resized with a drag handle. Multiline instructions make longer prompts easier to read and edit.

## Speech fixes

Newline-separated paragraphs retain their pauses during generation.

## Security and reliability

- Model and transcription downloads verify pinned digests; the built-in mirror requires a complete checksum manifest.
- Backup and restore reject unsafe file trees and backups larger than the available free space.
- Saved voice identifiers and model paths receive stricter validation.
- Logs redact sensitive download details and omit reference transcripts.
- The native Mac CLI server limits connections and message-read time, and keeps accepting clients after a bad connection or resource shortage.

## Updating

Models, saved voices, recordings and settings are retained. This release includes the native Mac CLI archive alongside the app downloads.
